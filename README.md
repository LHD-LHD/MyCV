# Hongda Li — Academic Website

Static academic website for Hongda Li, Technical Director at NIMO Labs.

## GitHub Pages deployment

1. Create a public GitHub repository. Use `<username>.github.io` for a root personal site, or another repository name for a project site.
2. Push the files in this directory to the repository's `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site will be available at `https://<username>.github.io/` for a root personal site, or `https://<username>.github.io/<repository>/` for a project site.

## Local preview

The site is plain HTML and CSS. Open `index.html` directly, or serve this directory with any static HTTP server.
